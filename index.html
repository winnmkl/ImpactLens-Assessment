Information Classification & Disposal
ClassificationScoreDescriptionHard Copy DisposalSoft Copy Disposal
Public3May be widely distributed without causing damage to the Organization, its employees, or stakeholders. No watermark required. Examples: Company brochures, marketing materials.Standard waste paper. Strip-cut shredder if any doubt.Remove directory entry. Physical media: shred or destroy.
Internal Use4-5Information intended only for use by employees. These documents should not be disclosed or circulated to external parties. Watermark: "CONTROLLED COPY".Strip-cut shredder or certified confidential waste bin.Remove directory entry. Physical media: secure destruction.
Confidential6-7Information that requires protection from unauthorized access. Should be circulated only to predefined individuals. Watermark: "CONFIDENTIAL".Strip-cut shredder or certified confidential waste bin.Overwrite file space + remove entry. Physical: approved destruction.
Restricted8-9Information that requires the highest level of protection. Distribution must be strictly controlled and logged. Watermark: "RESTRICTED".Cross-cut shredder + destruction record/audit trail required.Overwrite file space + destruction record. Physical: approved destruction.
